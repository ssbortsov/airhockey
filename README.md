# Аркада Суперлиги

Мобильные футбольные мини-игры в браузере.

- **Аэрофутбол** — аэрохоккей на футбольном поле против компьютера, 3 уровня сложности. Матч — 2 тайма по 1 минуте.
- **Вратарь** — по мотивам «Ну, погоди!»: мячи катятся по четырём желобам, вратарь ловит их перчатками. Три пропуска — конец игры, каждые 100 пойманных мячей снимают один пропуск.
- **Пенальти** — серия из 5 ударов: прицел касанием ворот, сила — удержанием. Вратарь прыгает за мячом.

Один файл `index.html` плюс картинки, без зависимостей и сборки.
